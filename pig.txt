5. Write a Pig Latin scripts to demonstrate different grouping operators on your data.
------------------------------------------------------------------------


A = LOAD 'emp.txt' USING PigStorage(',') AS (id:int, name:chararray, dept:chararray, salary:int); 
B = GROUP A BY dept; 
DUMP B; 
C = GROUP A ALL; 
DUMP C; 
D = FOREACH B GENERATE group AS dept, SUM(A.salary) AS total_salary; 
DUMP D; 
E = LOAD 'emp.txt' USING PigStorage(',') AS (id:int, name:chararray, dept:chararray, salary:int); 
F = COGROUP A BY dept, E BY dept; 
DUMP F;

6. Write a Pig Latin scripts to demonstrate different filtering operators on your data.
------------------------------------------------------------------------

A = LOAD 'emp.txt' USING PigStorage(',') AS (id:int, name:chararray, dept:chararray, salary:int); 
B = FILTER A BY salary > 30000; 
DUMP B; 
C = FILTER A BY dept == 'Manager' AND salary > 50000;
DUMP C; 
D = FILTER A BY dept == 'Clerk' OR salary > 50000; 
DUMP D; 
E = FILTER A BY NOT (dept == 'Clerk'); 
DUMP E;

7. Write a Pig Latin scripts to demonstrate Union, Split operator on your data.
------------------------------------------------------------------------

A = LOAD 'file1.txt' USING PigStorage(',') AS (id:int, name:chararray, marks:int); 
B = LOAD 'file2.txt' USING PigStorage(',') AS (id:int, name:chararray, marks:int);

DUMP C; 
SPLIT C INTO pass IF marks >= 80, fail IF marks < 80;
